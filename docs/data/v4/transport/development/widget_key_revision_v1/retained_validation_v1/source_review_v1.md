# Static review of the W3 validation templates

The preparation worker read the accepted W1 full-suite runner and helper,
corpus adapter, shared guard, comparator, freeze and preservation instruments,
outer owned runner, measurement and `settled_reading` helper. Their complete
original bytes and hashes are retained in `retained_instruments` and
`template_sources_v1.json`. This is a local source review; independent review,
rendered-byte freeze and launch acceptance belong to root.

The full-suite template changes its versioned identity, output paths and helper
filename. Its canonical pytest call and all executable custody/startup/discovery
checks remain the accepted v2 logic. The helper source is byte-identical to W1.
No focused-only observer executes through the full-suite entrypoint.

The corpus adapter's native call sequence remains unchanged. The shared guard
adds only the accepted safe-startup/optimization constraints and a declared
interpreter/one-CPU/priority check, along with W3 identity and path depth. CPU
selection and global scheduling remain external root decisions, not a new
reservation system in the guard.

The comparator changes the immediate predecessor from B1 to retained W1.
Because the predecessor schemas and command receipts differ, this is more
than a path substitution: it authenticates W1's preserved source/corpus/result
chain and accepted full-gate record, retains historical B1/G2 context, recognizes
W1's `-B` and W3's `-P -B` commands, and checks both available primary origin
ledgers. The exact six-component projection and G2 recursive difference
function remain unchanged. A retained predecessor's equality is required only
to authenticate its already accepted historical chain; no W3 equality is
required to write the comparison record.

The new templates were parsed with `ast.parse`, not imported or executed.
Static checks verify the unchanged corpus case map and semantic components,
the identical helper, the unchanged canonical pytest invocation, seven unique
job/output identities and the single comparison. Native acceptance remains
pending the later root-controlled execution.

The retained W1 full-suite preservation script is a source reference for the
result contract, not a newly executable W3 sealer. In particular, W3's canonical
full suite uses its separate full-suite freeze digest, while corpus/comparison
jobs use the source/corpus digest pair. Root's final preservation must bind
those distinct identities and must not pass this package to the unadapted W1
sealer as if they shared one digest pair.
