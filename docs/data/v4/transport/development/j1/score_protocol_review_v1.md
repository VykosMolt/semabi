`28f2887e0ff9e59ed183173024d76cee04f29325828a7116328bbf6ecb07025d`
and protocol_v1.md SHA-256
`897b89e75ecba96555bda621523f1af07fbc5904fd2a9c6220f2d1bbe0a51433`.
The independent invented-data harness passes 80/80 controls without changing

this acceptance does not admit an actual J1 run or any composition result.

I reviewed the complete core and protocol against the corrected live contract,
the native emission/Observation/outcome definitions, and the producer's stored
forecast value inventory and argument-event ordering. Scoring reads saved answers
and raw pages; it neither obtains a prediction retrospectively nor fits a model.
The protocol explicitly distinguishes a standing post-action frame from a claim
that the application emitted a new message, and records SILENT as the native
unchanged-text comparison. That policy is coherent with the stated prediction
question and does not make a causal state-change claim.

## Independent executable controls

The harness executes the actual core, native Observation, native emission
functions and Vocabulary, native outcome constants, and native Vouch and
ControlOutcome dataclasses. It uses the unchanged trace.Copier with an explicit
minimal native record-binding inventory to produce typed stored values. It does
not call native_bindings, any fit, native prediction/query, retrospective scorer,
browser, fixture service or custody CLI. All pages, labels, forecasts, control
records and checkpoints are invented. The 68 bound source files were rehashed
after execution; the run completed in its initial owned tool call with exit zero
and no live process or thread to reap.

Typed-data controls retain mapping insertion order, tuple keys, Counter and
defaultdict values, set/frozenset kinds, and exact integers through the native
large-decimal encoding, including a 241-bit mask and positive/negative encoding
boundaries. Canonically copied Observation snapshots decode with authenticated
snapshot hashes. Duplicate or Python-aliased mapping keys, duplicate/aliased or
unsorted set members, malformed decimal encodings, unknown copied objects and
missing/wrong/cyclic snapshot references reject. The scorer performs selective
typed inspection of saved values; full projection validity is still the caller's
custody obligation.

A saved startup checkpoint reconstructs an actual frozen emission Vocabulary
with exactly its stored value set. Calling native learn on an invented later
page leaves that set unchanged. Native lifting can use new values visible in
the submitted before/after pages without changing the saved vocabulary. A later,
Boolean-indexed or incomplete checkpoint, unfrozen vocabulary, wrong vocabulary
collection type and Boolean control-event count reject in the corresponding
core accessors. Native observed event counts retain their order and counts;
they are not treated as a closed output vocabulary.

The full native Vouch survives typed copying and decoding: event, ordered
witness tuple, condition tuple, coverage, exact Boolean sole flag and ordered
preceded_by tuple. Missing/extra fields, wrong record type/event, negative or
Boolean witnesses, Boolean coverage and integer sole flags reject. A Vouch
remains a preserved representative native justification, not a complete listing
of every surviving conjunction or the full fitted evidence.

The frame truth table checks changed and unchanged live-region text. The
standing matching ordinary frame is correct in both cases; an unrelated event
is wrong in both. SILENT is correct for unchanged text and wrong for changed
text. On an unchanged page a set containing both the standing frame and SILENT
retains both matches and remains ambiguous. Multiple wrong ordinary events do
not become corroborated just because text stayed unchanged. Missing poststate,
missing status channel and alert-only pages remain NO_CHANNEL under the native
status-role definition. An existing empty status region remains distinct from
no channel.

Decision-list UNDETERMINED and UNNAMED answers retain separate unestablished
reasons. RULE and LIST separately retain empty sets as unestablished, singleton
non-sole sets as forced correct/wrong, and multiple sets as ambiguous with
observed-among/observed-missing information. A sole-observed-vocabulary singleton
stays unestablished; sole-correct and sole-wrong are counted separately rather
than becoming forced evidence. A new frame absent from the saved control's
observed labels stays visible and is explicitly marked novel.

UNREACHABLE, NO_PRESTATE, NON_CLICK, NO_MODEL, ERROR, INCOMPLETE and missing saved
forecasts each remain outcome opportunities with explicit reasons. The aggregate
control contains 36 assessed opportunities; all three channel category counts
sum to 36. In that invented collection the decision-list counts are 18 correct,
five wrong and 13 unestablished. RULE and LIST each have 14 forced correct,
four forced wrong, four ambiguous and 14 unestablished. Their sole-correct and
sole-wrong counts are one each and remain within the unestablished category.
These numbers describe the harness only, not learner performance.

Literal arguments remain separate from frames. A matching frame with one wrong
endpoint yields a correct frame verdict and an explicit literal mismatch. Missing
bindings retain positions implied by the event's placeholder arity or saved role
map; no bound literal, missing observed position, FRESH and a nonmatching frame
receive their own unavailable reasons. FRESH requires a separately justified
creation/freshness control. Missing channels do not produce argument matches.
Malformed argument-event opportunity inventories and Boolean argument indices
reject. All assessed calls leave their saved response, raw pages and frozen
Vocabulary unchanged.

## Scientific protocol review

The primary first pass is one normally inferred native Fit from preserved raw
training observations and completed native Steps, with FROZEN_PREFIX at the
actual paired-step cut. No evaluation Step enters fitting. Identity or complete
representation assistance is conditional diagnostic work after first-pass
preservation under a separately reviewed intervention; supplied variables or
formulas do not become learned results. This matches the public live contract.

The allocation fixes 24 designated targets per split and predicts 313 charged
attempts, 312 paired Steps and one unpaired reset for each training, primary and
invariance collection. These are predictions to reconcile with the actual
Recorder and complete frozen allocation, not permission to drop failed or missing
positions. Failed/unreachable actions remain charged, and native complete:false
is an outcome rather than a reason to discard exhausted script accounting.
Setup, clicks and designated targets are reported separately.

The same resident predictor process and Fit continue across the primary and
permuted service profiles. Checkpoints, durable shutdown, explicit owned process
termination and immutable failed/partial identities are required. Prediction
contents cannot change the frozen script. The source and scoring policy freeze
precedes evaluation, while instrument validation uses disclosed data rather than
J1 cases. The allowed resource update is explicitly separated from immutable
historical fixture command examples.

The scientific question is relational composition, with zero/one/two-witness
rewiring contrasts, held-out endpoint combinations and a consistent renaming/
member-order permutation. The protocol distinguishes inadequate visible
representation/binding from missing variables or an insufficient searched
language, and distinguishes unresolved evidence from bounded search failure.
It does not infer observational equivalence merely because search failed.

Outcome accuracy alone is insufficient for either identity or composition.
A strong generated-fixture result requires the learned condition and bindings
to account for all relevant contrasts and held-out/invariance targets, with
independent visible-state, primitive-fidelity and literal-argument checks.
Visibility absence is unobserved rather than a negative relation fact. Identity
comparison needs the appropriate shared/union surface and contradiction controls;
an empty surface or one fitted reading is not identity agreement. Independent
real-application transfer remains a separate claim. These restrictions keep the
planned result within what its evidence can establish.

## Required caller and remaining phase obligations

This core exposes functions, not a complete custody gate. Its caller must first
authenticate source and native helper versions, the complete startup projection
and frozen training/model commitments, exact ready/predictor provenance, and
all saved request/response/receipt bytes. Native Observation.from_json itself
ignores unknown JSON fields; the caller must validate the raw observation schema
and exact association with the forecast's prestate and native decision's actual
poststate before injecting those pages here. A selectively extracted vocabulary
or outcome table is not proof of a complete model checkpoint.

The caller must join each charged native decision, Step/unpaired reset and
saved forecast exactly once, reconcile the entire ledger and fixed allocation,
retain missing positions in the full target denominator, check all independent
completion records, and preserve source/input/process/termination evidence.
This core's summary preserves the rows it receives; it cannot discover an omitted
row. Literal comparison denominators are the recorded event/position opportunities,
not proof that all fixed targets had available literal forecasts. Final reporting
must keep the full target outcome denominator and unavailable forecast positions
visible alongside any conditional literal-position rates.

State consequences, endpoint/selection fidelity, semantic rewiring and visibility,
training trace interpretation, identity diagnosis and actual fixture labels are
outside this core. The separate custody CLI and actual phase execution still
require review before an overall J1 result. This review opened no J1/R1 evaluator
script, fixture application, case, oracle or evaluation record. No candidate
source was edited, and no extra fit or broad learner test was needed.
