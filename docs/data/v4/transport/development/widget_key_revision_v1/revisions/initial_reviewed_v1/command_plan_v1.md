Unexpected predictions are retained; a missing selected unit or execution
failure retains the incomplete row and fails construction. Root must preserve
all rows and failure receipts, with no automatic retry or output overwrite.

artifact manifest and preserve its tool receipt outside that self-excluding

source snapshot. It cannot overwrite W1's original source/data/results or W2's
