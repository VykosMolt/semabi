# Exposure and execution boundary

This is a disclosed development control. Root and this author share the earlier
J1 source audit, retained training representation/model reports and the five
chosen raw observations. Neither the cohort nor the intervention is blinded.
The names and selected nodes were inspected before drafting this contract.

The author read the retained 45-observation training JSON to find exact matches
after removing only radio `checked`. All other observation fields remained in
that equality test. The author read copied native state, parsed-owner and
operator records in the retained training replay and inventory; these are
historical records, not results from a new W2 fit. Source reads traced raw
capture, parsing, abstract view construction, query search/denotation and
action binding. The manifest in `source_evidence_v1.json` records these inputs
and the exact source files used to prepare the draft.

`control_v1.py` imports only standard-library modules and has no command-line
entry point. It has been parsed and compiled as source only. It has not been
imported, called, or used to load native SemABI. No fresh fit, referring query,
forecast, held-out evaluation or outcome measurement was performed. Preparation
created files only in this directory. Root owns any later review, source freeze,
driver, native execution, raw preservation and independent assessment.

The callable takes a real resident Fit, the unchanged native `referring` module,
an authenticated retained `trace.Copier`, exact input bytes and a root-admitted
setup receipt. Receipt syntax checks do not authenticate those supplied objects.
The missing driver must bind their actual source/import origins, source freeze,
fit creation and input provenance, Copier schema and transition registration,
operator record digest, raw-to-normalized associations, and runtime custody.
No such W2 J1 setup or driver is presently admitted.

The receiver binding used in the four checked examples is identity-assisted
diagnostic input from raw observation plus admitted native ownership. It is
outside the operator's original training-positive evidence. Selection search
agreement with that binding is not an independent correctness check. The fifth,
unchecked observation is used only for denotation checks. A later independent
assessment must check correspondence against the raw local visible owner.

The draft fixes the historical `op0`, `?o0: T1`, `?o1: T0`, Transmit core and
node-17 action selector as setup requirements. Those constants do not encode
which receiver is checked. The receiver value is derived from the currently
checked raw radio and its existing parsed owner; no receiver-name table appears
in the code. A missing or changed operator, owner or parameter stops injection.
Only the actual parsed family key is used. The native collection-position guard
is recomputed on empty, equal copied caches and may veto that same key.

All returned candidates and complete denotations are retained, including empty
or plural results. The callable returns raw diagnostic records and no success
verdict. Its process-local object identity tokens are equivalence audit metadata
and are never used to encode a view value or supply a query answer. Mutation,
copy, setup and native-call failures remain explicit. Nothing here establishes
JOIN correctness, patch identity, references, intermediate witnesses, persistent
radio semantics or production transport capability.
