## Generic evaluator adapter

The adapter imports only the retained standard-library control helper. Its CLI
requires a completed preservation manifest covering all seven inputs: score,
observations, steps, decisions, configuration, adapter and helper. This specific
post-preservation manifest uses root-relative SHA-256 strings, as the public
envelope declares. That interface differs from the G2 results inventory's
structured entries and must be supplied accordingly. It also verifies that raw
evaluation hashes match the saved score, rejects input/output aliasing, uses an
exclusive output and checks for input changes during diagnosis.

Its generic logic preserves every configured task for present and pending
models, including missing or duplicate queries and missing targets. Script
decisions must correspond to unique raw steps, preserve requested actions and
raw custody fields, occur in order, and identify the unique configured target
ordinal. Independent metrics retain raw target resolution, primitive kinds and
literal arguments separately from raw fields and learned bindings. Failed
actions remain visible. Metric denominators follow the fixed cases eligible for
each configured operation; the full task denominator remains explicit.

The corrected adapter checks targeted selection as well as other node-targeted
primitives, and mirrors the collector's literal precedence for reset/reload/press
and other actions. The retained helper requires independent visible anchors and
exact names for identity, reports unavailable identity explicitly, and does not
promote value-only coincidence to field identity. Optional field trajectory
alignment remains labelled as supplied oracle diagnosis. Same-name learned-key
consistency is reported separately. Response accuracy does not enter this
control. These are generic implementation conclusions; reserved configuration
adequacy remains the sealed evaluator's scope.

The preserved synthetic adapter record reports 15 new checks and 24 retained
utility checks passing. Its source and record hashes match the final inventory.
They were inspected without rerunning the adapter or opening its configuration.

The original public commands omitted idle I/O and the required owned-job wrapper.
The final envelope fixes both collector commands, describes distinct scorer job
identities and separately owned fixture-service provenance, and retains the
previous envelope revision. The announced 22-entry inventory is also preserved;
the final inventory adds its four public dependencies to the primary map without
changing prior entries. No freeze used either superseded public revision.
