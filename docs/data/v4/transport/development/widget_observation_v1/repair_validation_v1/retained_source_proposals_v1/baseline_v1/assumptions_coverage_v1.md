# W2 observation regression proposal: baseline v1

This is an unexecuted test proposal for the frozen main-worktree
`widget_observation_v1/repair_contract_v3.md`. W2's report, diagnostic and
invented inputs, and W3's identity-revision report are disclosed development
evidence. These regressions are neither blind nor fresh transfer evidence.
The manifest records their exact source bindings.

The proposed test file is frozen beside this note as
`test_v4_objective.py.txt`; `test_changes.patch` is the exact test-only diff
against `2025ee5b8d3c6b4e0ae376a7426e6c2a3ced7399`. The base test bytes are also
retained. All eight original tests and the original helper retain their exact
function ASTs. Only this existing test file is proposed for test execution.
No native code, pytest collection, diagnostic instrument or corpus ran during
preparation. Root owns source acceptance and all subsequent execution.

## Fixture assumptions and public behavior

- The observations and successful actions are invented. Unit templates and
  selected keys are supplied candidate decisions; `ObsGraph`, `parse_units`,
  native slot statistics, entity-type construction, the V4 abstractor, state
  diff and full `evaluate` remain real. No new observation helper or W3 private
  parser interface is imported by the tests.
- Numeric keys avoid relying on incidental vocabulary learning. The reference
  fixture also supplies two collection members whose names vary at the same
  native position. It explicitly configures a reference to a composite-keyed
  target, so an unresolved changing number must use an unchanged name span
  in the fallback control.
- The W2 positive uses the actual persistence method with two distinct,
  same-key calibration pairs, then scores only key `3` changing red to blue.
  Calibration status changes are outside the selected units. Configured
  persistence is tested separately, without inferred reload support.
- Every widget-only verdict test first asserts that the unchanged V2 predicate
  is false. Native state/delta assertions establish the important causal
  preconditions before the expected verdict. The churn control separately
  retains non-widget evidence and the native complete-collection tracker.
- The stale-source control caches real emitted instances, then wraps the public
  normal parser to clear active slots or remove a node binding. This is a
  disclosed diagnostic state at the source boundary, not a claim that native
  frame transfer independently creates that complete cached state. A separate
  native inherited-frame case asserts the real cleared slots and leftover
  frame bindings, and earns credit only through the supported child field.
- Step verdicts stay coarse. A qualifying field can support the existing step
  classification; checking `delta_atoms` does not prove each atom is separately
  grounded, validate the supplied identity, or repair J1's missing bindings.

and verified-view contradictions; and churn.

## Limits and review obligations

Fixture validity has only been checked from source and ASTs. A runtime failure
at a fixture or state precondition must be reported with its actual cause and
preserved separately from a scoring assertion; it must not be relabeled as an
expected omission or made to pass by weakening the contract.

The proposed assertions do not depend on the W3 private API. Production reuse
of that interface, including raw composite/button witnesses and normal-cache
isolation, remains subject to the separate W3 source acceptance. No unresolved
source question requires changing the proposed W2 verdicts. Root must decide
source acceptance, baseline/candidate commands and any later revision; this
frozen directory must remain unchanged after execution begins.
