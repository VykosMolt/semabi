## What the training diagnosis establishes

The complete saved training trace has 45 observations and 312 Steps. Its raw
observations contain 360 patch-row occurrences and 720 endpoint combobox
occurrences. The native hypothesis structure retains them as unit candidates,
with an outer row and an inner two-label field template, but both final keys are
null. The final model has only the four transmitters and four receivers, with
zero references. Patch names and endpoint values survive as view/static data;
they are not missing from the recorded interface.

One unchanged training-only Fit and compile captured the search result omitted
from the resident trace. Root independently compared the complete replayed and
saved projections and found exact equality. The actual search demotes outer
`group#0` and inner `text#0` identities on exact evidential ties, recording them
as unearned while keeping the alternative readings in open questions. Explained
behavior, errors and named actions do not change; complexity falls 24→17→12 as
a consequence. This authenticates the executed tie-handling decision. It does
not prove either ontology true or prove that a particular repair earns identity.

The demonstrated path has several distinct boundaries:

- Endpoint widgets retain the `~` transient suffix. With no qualifying
  `H.reload_pairs`, none is promoted into attributes or reference discovery.
  Restoring the outer row identity alone cannot supply its endpoint relations.
- Identity readings nevertheless report reload stability 1.0. Their separate
  reload filter includes the sole step-zero reload whose before/after signature
  is identical; it compares each stored instance to itself. That number is not
  evidence of widget persistence after a state-changing reload.
- The underlying raw-change score excludes widget nodes even when the model
  treats their values as attributes. A promoted-widget delta therefore need
  not become explained behavior. A controlled per-step comparison is still
  required to establish that counterfactual.
- The inner field template mixes transmitter and receiver values in one slot.
  Reference discovery chooses one target type per template/slot; promotion
  alone does not establish both endpoint types or their attachment to a row.
- Receiver checked state remains in parsed instance slots but does not reach
  the current object-property/view naming-query inputs. A transient selection
  can be useful naming evidence without being declared durable domain state.

The static source audit and matched replay establish these boundaries, not the
sufficiency of a persistence-only fix. Controlled follow-ups must distinguish
widget observation fidelity, justified persistence, contextual field attachment,
both endpoint reference types, receiver binding, and existential-witness search.
The earlier supplied-conjunction native control remains a separate language
test; it does not demonstrate normal induction on this trace.
